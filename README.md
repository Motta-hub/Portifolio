💻 Portfólio Pessoal

Este projeto consiste no desenvolvimento de uma página de portfólio pessoal, criada com o objetivo de apresentar minha trajetória acadêmica, experiências profissionais, conhecimentos técnicos e projetos desenvolvidos na área de tecnologia.

A página está sendo desenvolvida como parte do meu processo de aprendizado e aprimoramento em desenvolvimento Web, buscando aplicar na prática conceitos de estruturação, estilização e organização de páginas.

🚀 Tecnologias utilizadas
HTML5 — Estruturação da página
CSS3 — Estilização, layout e responsividade
JavaScript — Interações e funcionalidades (caso utilizado no projeto)
📌 Sobre o projeto

O portfólio possui como principais objetivos:

Apresentar meu perfil profissional e acadêmico;
Demonstrar meus conhecimentos em programação e desenvolvimento Web;
Apresentar projetos desenvolvidos durante minha trajetória acadêmica e pessoal;
Disponibilizar informações de contato e redes profissionais;
Praticar conceitos de desenvolvimento Front-end.

A estrutura pode sofrer alterações conforme o desenvolvimento do projeto.

🎯 Objetivos

Este projeto faz parte do meu processo de evolução na área de tecnologia. Por meio dele, busco desenvolver não apenas conhecimentos técnicos, mas também boas práticas relacionadas à organização de código, desenvolvimento de interfaces e experiência do usuário.

Atualmente, estou graduando em Análise e Desenvolvimento de Sistemas e tenho interesse em aprofundar meus conhecimentos em programação, especialmente em Java e desenvolvimento Back-end, além de continuar evoluindo minhas habilidades em desenvolvimento Web.
